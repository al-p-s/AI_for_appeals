# Классификатор обращений граждан

Проект по автоматической классификации обращений граждан в администрацию города по тематическому классификатору Администрации Президента РФ.

## Задача

На вход — скан обращения (PDF). На выход — одна или несколько категорий из официального классификатора (коды уровня `xxxx.xxxx.xxxx.xxxx`).
А также - извлеченные ключевые поля для дальнейшего формирования карточки обращения (планируется последующая интеграция в систему документооборота).

## Модели

**GeRaCl-USER2-base** — zero-shot классификатор для русского языка, 155M параметров. Не требует дообучения под конкретные классы: на вход подаётся текст и список меток, модель выбирает наиболее подходящую. Построен поверх USER2-base.

**RuModernBERT-small** — лёгкий русский энкодер, 35M параметров, контекст до 8192 токенов. Вариант для дообучения если zero-shot окажется недостаточным.
